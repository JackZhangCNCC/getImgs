# 网页图片批量下载工具

这个工具包含两个Python脚本，用于从网页批量下载图片，特别是针对那些使用复杂结构（如多层section）而导致无法通过右键菜单保存图片的网站，例如微信公众号文章。

## 最新更新 (v1.1)

- 增强了错误处理和日志记录
- 添加了循环下载功能，可连续下载多篇文章
- 改进了命令行中文显示
- 增强了ChromeDriver兼容性检测
- 修复了可能导致程序崩溃的错误

## 功能特点

- 支持从普通网页下载图片
- 专门优化对微信公众号文章的支持
- 自动处理验证页面（需用户交互）
- 过滤小图标和无关图片
- 自动创建以文章标题命名的文件夹
- 保存高质量的原始图片
- 记录所有图片URL便于参考
- 支持连续下载多篇文章

## 使用前准备

1. 确保已安装Python 3.6+
2. 安装所需依赖库：

```bash
pip install requests beautifulsoup4 selenium
```

3. 下载与您Chrome浏览器版本匹配的ChromeDriver：
   - 查看Chrome浏览器版本：点击右上角三点菜单 -> 帮助 -> 关于Google Chrome
   - 下载地址：https://chromedriver.chromium.org/downloads
   - 将下载的chromedriver.exe放在脚本同目录下

## 使用方法

### 1. 使用批处理文件（推荐）

直接双击运行`download_wechat_images.bat`：

1. 输入微信公众号文章URL
2. 可选：输入ChromeDriver路径（如果放在同目录下可直接回车）
3. 等待下载完成
4. 选择是否继续下载其他文章

### 2. 手动命令行运行

```bash
python getWechatImgs.py https://mp.weixin.qq.com/s/your_article_id
```

参数选项：
- `-o, --output`: 指定输出目录 (默认: ./wechat_images)
- `-m, --min-size`: 最小图片尺寸(像素) (默认: 200)
- `-w, --wait`: 等待页面加载的时间(秒) (默认: 10)
- `--no-filter`: 不过滤小图片和图标
- `--headless`: 使用无头模式(不显示浏览器)
- `--driver-path`: 指定ChromeDriver路径

## 常见问题解决

### Chrome WebDriver相关错误

如果项目自带的ChromeDriver不好用，有相关错误，请阅读参考`ChromeDriver配置指南.md`的方案。

### 未找到图片

如果程序无法找到图片：

1. 确保URL是完整的微信公众号文章链接
2. 检查是否需要登录才能查看文章
3. 使用非headless模式运行，完成可能的验证步骤

## 注意事项

1. 请遵守网站的服务条款和版权规定
2. 不要过于频繁地使用工具，以避免IP被封
3. 下载的图片仅供个人使用
4. 微信公众号文章需要先解决验证问题才能正常抓取

## 工作原理

1. 使用requests或Selenium获取网页内容
2. 解析HTML查找所有图片元素
3. 从img标签中提取图片URL（处理各种属性如src, data-src等）
4. 过滤无关图片（如小图标）
5. 下载高质量版本的图片
6. 保存到指定目录

## 常见问题

### 无法获取微信公众号图片

可能原因：
- 需要完成验证（使用非headless模式，按提示完成验证）
- 图片使用了特殊加载方式（尝试增加等待时间: `-w 20`）
- 网络连接问题（检查网络连接）

### 图片质量不佳

对于微信图片，脚本会尝试获取高质量版本，如果仍然不理想，可以尝试修改`process_wechat_img_url`方法中的参数。
